# شاشة الصور (CYD ESP32-2432S028)

الشاشة تعرض صورة كاملة، ولمسة على الشاشة تنقلك للصورة اللي بعدها.

## أول مرة
1. اعمل Repository جديد على GitHub وارفع كل الملفات دي فيه (الفرع `main`).
2. من Settings ثم Pages، اختار Source: **GitHub Actions**.
3. من تبويب Actions استنى الـ build يخلص (حوالي 5 دقايق).
4. الرابط بتاعك: `https://USERNAME.github.io/REPO/` وافتحه من Chrome أو Edge على الكمبيوتر، واضغط تثبيت.

## تضيف صورة أو تغيّرها
حط الصور في فولدر `images/` بأسماء مرتبة: `01.jpg` و`02.jpg` و`03.jpg`.
أي صورة بتتقص من النص تلقائياً عشان تملا الشاشة (320×240 عرضي).
ارفع التغيير وانتظر الـ build، وبعدها اضغط تثبيت من نفس الرابط.
